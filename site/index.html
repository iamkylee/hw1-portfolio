Research & Projects研究與專案

APNOMS 2025 · IEEE · Sole author獨立作者

Intent-Driven Autonomous Reconfiguration for Telecom OSS

A Generative-AI-Empowered Hierarchical Multi-Agent Architecture

Problem. Service re-provisioning in telecom touches many legacy OSS systems; each change needs an expert to translate a business request into dozens of system-specific steps. 問題：電信服務改接牽涉多套既有 OSS 系統，每次變更都需要專家把業務需求翻譯成大量系統操作步驟。

My role. I chose the topic, designed the architecture, built the prototype, ran the experiments and wrote the paper — independently. 我的角色：題目、架構、方法、實驗與論文撰寫皆由我獨立完成。

Approach. A Chief Agent decomposes an operator's intent and delegates to specialist agents. I introduced a Primary-Key Pattern and a Command Pattern for agent-to-agent communication so that data passed between agents stays unambiguous. 方法：由 Chief Agent 拆解維運意圖，再委派給各專責代理人；並提出 Primary-Key Pattern 與 Command Pattern 作為代理人間的溝通方式，確保傳遞資料不失真。

Result. 0% error rate on the evaluated reconfiguration tasks; the pattern generalises to other multi-system industries such as finance. 成果：在實驗的改接任務中達到 0% 錯誤率，架構可延伸至金融等多系統產業。
